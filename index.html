Research Philosophy & Focus

Bridging hardware architecture, discrete-event simulation, and low-level systems programming.

What draws me to computer architecture is the challenge of dissecting complex execution pipelines, identifying bottlenecked memory traffic, and engineering hardware-software co-designed solutions. Modern computational demands (from deep learning workloads to extreme-scale scientific simulations) are bottlenecked not by arithmetic units, but by data movement, memory hierarchies, and interconnects. My goal is to discover architectural and runtime mechanisms that make multi-GPU systems dramatically more efficient and scalable.

Multi-GPU Memory & Coherence

Investigating shared virtual memory, cache coherence protocols, and directory structures across non-uniform memory access (NUMA) multi-GPU topologies to slash remote memory access latency.

Cache Coherence NUMA Locality Shared Memory

Interconnects & NoC Bottlenecks

Analyzing cross-GPU interconnect saturation, NVLink/PCIe traffic modeling, and memory controller arbitration under heavy contention in multi-tenant and parallel workloads.

Interconnects Traffic Modeling Arbitration

Architectural Simulation

Modeling hardware behaviors using MGPUSim (discrete-event Go-based GPU simulator). Simulating compute units, memory pipelines, and interconnects for empirical architectural evaluation.
